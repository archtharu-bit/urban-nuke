# Contributing

Thanks for helping improve **Urban Nuke**.

## Principles
- Keep changes small and reviewable
- Prefer report-only behavior by default
- Avoid destructive actions unless explicitly opt-in

## Workflow
1. Create a feature branch
2. Make minimal, focused changes
3. Run `scripts/self-test.ps1`
4. Open a pull request with a clear summary

## Reporting
- Attach relevant report files from `reports/` (redact sensitive data).
- Include OS and PowerShell version for bug reports.
