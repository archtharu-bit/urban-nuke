# MySQL Performance Tuning (Windows)

This guide applies safe, general-purpose tuning for a 16 GB RAM laptop.

## Summary of Changes
- Increase InnoDB buffer pool to 4 GB.
- Increase redo log capacity to 512 MB.
- Increase InnoDB log buffer to 64 MB.
- Align `max_heap_table_size` with `tmp_table_size`.
- Reduce buffer pool instances to match pool size.

## Apply Automatically
Generate a proposed tuned file (safe; does not modify `my.ini`):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\mysql-tune.ps1
```

Apply changes (requires Administrator; writes to `my.ini` and creates a timestamped backup):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\mysql-tune.ps1 -Apply
```

Target file:
`C:\ProgramData\MySQL\MySQL Server 8.0\my.ini`

## Apply Manually
1. Backup `my.ini`.
2. Open `C:\ProgramData\MySQL\MySQL Server 8.0\my.ini` as Administrator.
3. Apply the settings listed in `reports\my.ini.tuned` generated by the script.
4. Restart the MySQL80 service.

## Restart MySQL Service
```powershell
Restart-Service MySQL80
```

## Notes
- These are general defaults, not workload-specific.
- If you run multiple heavy apps, reduce `innodb_buffer_pool_size` to 2G.
- Always re-check performance after changes.
