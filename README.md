# Workspace Setup

This folder contains VS Code and Continue configuration.

## Required Environment Variables
Set these in your OS environment or a secrets manager (do not commit them):

- `OPENAI_API_KEY`
- `ANTHROPIC_API_KEY` (only if using Anthropic models)

## VS Code Extensions
Install the recommended extensions from `.vscode/extensions.json`.

## Notes
- GitHub Copilot requires you to sign in to GitHub inside VS Code after installation.
