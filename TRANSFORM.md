# 🚀 Super Lap Transformation Guide

Transform your system into a high-performance machine with automated optimization.

## Quick Start

### 1. Preview Changes (Safe)
```powershell
powershell -ExecutionPolicy Bypass -File scripts\transform-system.ps1
```

### 2. Apply All Changes
```powershell
powershell -ExecutionPolicy Bypass -File scripts\transform-system.ps1 -Apply
```

## Individual Scripts

Run specific optimizations:

```powershell
# Full system optimization
powershell -ExecutionPolicy Bypass -File scripts\super-optimizer.ps1 -Apply

# Restructure folders only
powershell -ExecutionPolicy Bypass -File scripts\restructure-folders.ps1 -Apply

# Skip drivers update
powershell -ExecutionPolicy Bypass -File scripts\super-optimizer.ps1 -Apply -SkipDrivers

# Skip apps update
powershell -ExecutionPolicy Bypass -File scripts\super-optimizer.ps1 -Apply -SkipApps
```

## Safety

- All scripts run in DRY-RUN mode by default
- Review changes before applying
- Requires admin privileges for system changes
- Restart recommended after completion
